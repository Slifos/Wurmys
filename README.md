# Wurmys

## Wurmys est un jeu de platforme en 1 contre 1, où des vers se battent au péril de leurs 3 vies pour gagner match et ainsi remporter la victoire.
	Pour ce faire ils seront armées de 2 armes interchangeables: une épée qui fait des dégats au corps à corps et un arc pour tirer à distance.

### Prérequis
-[python](https://www.python.org/downloads/) (avec pip)
-[pygame] (entrez dans le terminal -> pip install pygame) (https://www.pygame.org/news)

#### Installation du projet:
(1)Download le projet git
(2) extraire le fichier zip
(3) ouvrir l'ensemble du fichier extrait dans un ide python (vscode,pycharm, etc..)
(4)Avant de lancer, verifier que pygame est bien installé
-> aller dans le terminal -> écrivez: "pip install pygame"
(5) une fois installé lancez le fichier "main.py"
(6)Le jeu est prêt à être lancé :)
